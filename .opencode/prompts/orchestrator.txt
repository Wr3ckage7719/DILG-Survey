## Project Context
This is a DILG (Department of Interior and Local Government) Client Satisfaction Survey web app:
- **Stack**: React 18 + TypeScript + Vite + Tailwind CSS v3 + shadcn/ui
- **UI libs**: Framer Motion, Lucide React, sonner (toasts), next-themes (dark mode)
- **Components**: Radix UI primitives (Select, RadioGroup, Progress, Separator, Slot)
- **Structure**: Multi-step form wizard with 5 sections (Office → Demographics → CC → SQD → Feedback)
- **Design**: Navy/gold DILG branding, step indicator, Lottie trophy animation on submit
